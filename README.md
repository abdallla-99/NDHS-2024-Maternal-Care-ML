# Predicting Maternal Healthcare Dropout in Nigeria Using Machine Learning

## Overview
This repository supports the research manuscript, "Predicting dropout from antenatal care, facility delivery, and postnatal care in Nigeria using machine learning: evidence from the 2024 Nigeria Demographic and Health Survey."

## Repository contents
- `Topic_3_Predicting_the_Dropout_from_Antenatal_Care.ipynb`: Jupyter notebook currently provided in this repository.

## Data source and access
The study uses data from the 2024 Nigeria Demographic and Health Survey (NDHS). Individual-level survey data are not included. Researchers should obtain authorized access directly from The DHS Program and follow its terms of use.

## Running the notebook
Use Python in Jupyter Notebook or Google Colab. Review the notebook for required packages, input file names, and data paths. Authorized survey data may be required.

## Reproducibility and privacy
Do not upload restricted survey microdata, credentials, or confidential information.
